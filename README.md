# Chat Time

A lightweight Foundry VTT module that replaces the default chat message timestamp ("5 minutes ago") with your local real-world time and date.

## Features

- Shows your local time and date on every chat message (hover it for the full date with seconds)
- 12-hour or 24-hour clock, chosen by each player
- Hides Foundry's default timestamp while turned on
- Turn it on or off for yourself without affecting other players

## Settings

Found under **Game Settings → Configure Settings → Chat Time**. Both are personal settings:

- **Show Local Time**: on or off
- **Clock Format**: 12-hour or 24-hour

## Compatibility

Foundry VTT v14, D&D 5e system v6.
